# Змейка — настольная сборка для Windows

Обычное окно, Python на компьютере не нужен. Игра та же, что в
`../snake_tk.py`: стрелки/WASD, пробел — пауза, R — заново, Esc — выход.

![Вид игры](preview.png)

## Что запускать

| Файл | Как использовать |
|------|------------------|
| `Zmeika-portable.zip` | Распаковать в любую папку и запустить `Zmeika.exe`. Проверено: окно 730×608, игра работает. Папку `_internal` рядом с exe не удалять и не разделять с ней exe. |
| `dist/Zmeika.exe` | Один файл, 10 МБ — ничего распаковывать не нужно. Собран тем же кодом; при первом запуске Windows может проверить его дольше. |

Оба варианта не подписаны, поэтому SmartScreen может показать «Windows
защитила ваш компьютер» — нажмите **Подробнее → Выполнить всё равно**.
Это нормально для самосборных exe.

Рекорд хранится в `snake_highscore.txt` рядом с exe.

## Как пересобрать

Нужен Python 3.11+ и интернет (PyInstaller скачается с PyPI):

```powershell
powershell -ExecutionPolicy Bypass -File desktop\build.ps1
```

Скрипт соберёт `desktop\dist\Zmeika.exe`. Чтобы получить «портативную»
папку (как в zip), замените в команде PyInstaller `--onefile` на `--onedir`.

## Из чего собрано

- `app.py` — точка входа: подхватывает `snake_tk.py` и кладёт файл рекорда
  рядом с exe (внутри onefile `__file__` указывает во временную папку).
- `icon.ico` — иконка приложения (из `android/icon.png`).
- Логика и интерфейс — общие с `../snake.py` и `../snake_tk.py`, отдельной
  копии кода здесь нет.
